# FigureCraft
วิธีใช้งานเว็บไซด์ฟิกเกอร์คราฟ
1). สมัครบัญชีผู้ใช้ใหม่โดยคลิกที่ปุ่ม Sign in แล้วคลิก "สมัครสมาชิก" จากนั้นใส่ชื่อ อีเมล และรหัสผ่าน
2). หลังจากสมัครสมาชิกแล้ว ระบบจะนำมายังหน้าเข้าสู่ระบบ ใส่อีเมลและรหัสที่ได้สมัครไว้
3). ระบบจะนำมาสู่หน้าหลัก คลิกปุ่ม "เพิ่มฟิกเกอร์" เพื่อเพิ่มฟิกเกอร์ที่ต้องการ
4). ที่หน้าเพิ่มฟิกเกอร์ ให้ผู้ใช้กรอกชื่อฟิกเกอร์ ค่ายผู้ผลิต หมวดหมู่ประเภทของฟิกเกอร์ ร้านค้าที่ซื้อ ราคา วันที่สั่งซื้อ/ได้รับ สถานะสินค้า สถานะการต่อ และอัพโหลดรูปของฟิกเกอร์เป็นไฟล์ .JPG หรือ .PNG หลักจากนั้นให้กดบันทึกข้อมูลเพื่อเพิ่มฟิกเกอร์ลงในเว็บไซด์
5). หลักจากบันทึกข้อมูลแล้ว เว็บไซด์จะส่งผู้ใช้มาที่หน้าหลัก ฟิกเกอร์ที่ถูกเพิ่มจะปรากฏเป็น Figure cards อยู่บนหน้าหลัก
6). หากผู้ใช้กดที่ Figure card ระบบจะนำผู้ใช้ไปยังหน้าแสดงข้อมูลของฟิกเกอร์นั้นๆ โดยจะแสดงรูปและข้อมูลต่างๆที่ผู้ใช้กรอกไว้ และผู้ใช้สามารถเพิ่ม Custom Notes ได้ที่ด้านล่างของหน้าข้อมูลฟิกเกอร์ โดยให้กดปุ่มแก้ไขที่มุมขวาบนของช่อง Custom Notes ผู้ใช้สามารถเพิ่ม Detail Note สำหรับงานดีเทลหรือเดินลาย Paint Note สำหรับงานทำสีหรือพ่นสี และ Decal Note สำหรับงานติดดีเคล
7). ที่หน้าหลัก หากผู้ใช้กดปุ่ม Dashboard ที่ด้านบนขวา ระบบจะนำผู้ใช้ไปที่หน้า Dashboard โดยหน้านี้จะแสดงข้อมูลโดยรวมของคลังของผู้ใช้ ประกอบด้วยจำนวนโมเดลทั้งหมด จำนวนโมเดลที่ต่อแล้ว จำนวนโมเดลที่ยังไม่ได้ต่อ มูลค่าคลังรวม จำนวนโมเดลแบ่งตามหมวดหมู่ รายการโมเดลค้างต่อล่าสุด และความคือหน้าในการประกอบของคลังทั้งหมด
8). หากผู้ใช้กดปู่ม Setting ระบบจะนำผู้ใช้ไปยังหน้าการตั้งค่า โดยผู้ใช้สามารถเปลี่ยนชื่อ Username และสามารถเป็นการแจ้งเตือนแบบ Pop-up เมื่อเข้าหน้า Dashboard ได้ โดยระบบจะแสดงรายชื่อฟิกเกอร์ที่ยังไม่ได้ต่อวันละหนึ่งครั้ง
